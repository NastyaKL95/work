#### Задача A. Шторы-мини

Дан массив высот:

`3 3 1 4 4 0 2 2 5 1`

Разрешена операция: выбрать отрезок и уменьшить на 1 все **положительные** элементы этого отрезка (элементы, равные 0, не изменяются).

Найдите минимальное число операций, чтобы все элементы стали равны 0.

**Формат ответа:** одно целое число.

---

#### Задача B. Лифт-инвертор

Есть дом с этажами `1..7`. Стартовый этаж: `X = 3`.

Команды:

- `U` - попытка подняться на этаж выше;
- `D` - попытка опуститься на этаж ниже;
- `S` - переключение режима инверсии (команды `U` и `D` меняются местами).

Если ход выходит за границы `1..7`, лифт остается на месте. Это считается ударом о границу.

Строка команд:

`UUUSDDDDSSUUUD`

Найдите:

1. конечный этаж;
2. количество ударов о границу.

**Формат ответа:** два целых числа через пробел.

---

#### Задача C. Маятниковая строка

Дана строка `s` длины `n`.

Обрабатывайте символы слева направо:

- символ на нечетной позиции (1, 3, 5, ...) добавляется в конец новой строки;
- символ на четной позиции (2, 4, 6, ...) добавляется в начало новой строки.

Выведите полученную строку.

**Входные данные**

- первая строка: `n` (`1 <= n <= 2*10^5`);
- вторая строка: `s` (строчные латинские буквы, длина `n`).

**Выходные данные**

- одна строка - результат преобразования.

---

#### Задача D. Шторы-online

Дан массив `h1..hn`, где `0 <= hi <= 10^9`.

Разрешена операция: выбрать отрезок `[l, r]` и уменьшить на 1 все **положительные** элементы этого отрезка (нули не изменяются).

Найдите минимальное число операций, чтобы все элементы массива стали равны 0.

**Входные данные**

- первая строка: `n` (`1 <= n <= 2*10^5`);
- вторая строка: `h1 h2 ... hn`.

**Выходные данные**

- одно целое число - минимальное число операций.

---

#### Задача E. Дублирующий редактор

Нужно получить строку `s` из пустой строки, используя операции:

1. `ADD` - дописать следующий символ `s` (в порядке слева направо);
2. `DUP` - удвоить текущую строку (`t -> t+t`).

Найдите минимальное количество операций, необходимое для получения строки `s`.

**Входные данные**

- одна строка `s`, `1 <= |s| <= 2*10^5` (строчные латинские буквы).

**Выходные данные**

- одно целое число - минимальное количество операций.

3. Ввод и вывод - через стандартные потоки.

### 2.3. Таблица задач

| № | Название | Максимум |

### 2.4. Условия задач

#### Задача A. Стабилизация таймлайна

Даны целые числа `t1..tn`. Требуется подобрать `a1..an` так, чтобы:

- `|ai - ti| <= D` для всех `i`;
- `a1 < a2 < ... < an` (строго возрастающая последовательность).

Найдите минимально возможное значение `D`.

**Входные данные**

- первая строка: `n` (`1 <= n <= 2*10^5`);
- вторая строка: `t1 t2 ... tn` (`|ti| <= 10^9`).

**Выходные данные**

- одно целое число - минимальное значение `D`.

---

#### Задача B. Маршрут с двумя режимами

Дан неориентированный граф из `n` вершин и `m` ребер.  
У каждого ребра две стоимости: `day` и `night`.

Старт: вершина `1`, режим `day`.

В любой вершине можно переключить режим за стоимость `p[v]`.

Найдите минимальную стоимость пути из вершины `1` в вершину `n`, либо `-1`, если путь отсутствует.

**Входные данные**

- первая строка: `n m` (`1 <= n <= 2*10^5`, `0 <= m <= 2*10^5`);
- вторая строка: `p1 p2 ... pn` (`0 <= p[v] <= 10^9`);
- далее `m` строк: `u v c_day c_night`.

**Выходные данные**

- одно целое число: минимальная стоимость или `-1`.

---

#### Задача C. Цепная склейка отчетов

Даны строки `s1, s2, ..., sm` в фиксированном порядке.  
При склейке соседних строк разрешено перекрытие: суффикс `si` совпадает с префиксом `si+1` (берется максимально возможное перекрытие).

Найдите минимальную длину итоговой строки после последовательной склейки.

**Входные данные**

- первая строка: `m` (`1 <= m <= 2*10^5`);
- далее `m` строк `s1..sm`;
- суммарная длина всех строк не превосходит `4*10^5`.

**Выходные данные**

- одно целое число - минимальная длина итоговой строки.

---

#### Задача D. Квадраты датчиков

Даны `n` точек с целочисленными координатами.  
Нужно посчитать количество квадратов со сторонами, параллельными осям координат, у которых все 4 вершины присутствуют в наборе точек.

**Входные данные**

- первая строка: `n` (`1 <= n <= 4000`);
- далее `n` строк: `x y` (`|x|, |y| <= 10^9`).

**Выходные данные**

- одно целое число - количество квадратов.

---

#### Задача E. Сегментация шума

Дан массив `a1..an`. Требуется разбить его на `k` непустых подряд идущих сегментов.  
Цена сегмента `[l..r]` равна `max(a[l..r]) - min(a[l..r])`.

Найдите минимально возможную сумму цен всех сегментов.

**Входные данные**

- первая строка: `n k` (`1 <= k <= n <= 2000`, `k <= 50`);
- вторая строка: `a1 a2 ... an` (`|ai| <= 10^9`).

**Выходные данные**

- одно целое число - минимальная сумма цен сегментов.
